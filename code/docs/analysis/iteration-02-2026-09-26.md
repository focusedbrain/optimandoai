## Findings recorded in the contract

- The conflict between v1.0's all-public reads and §XVI.6.3 plus ruling 3 is resolved by the public/account tiers (Q20 A). The client work is C7.
- Several signed objects (head, embedded delegation, manifest, directory record) are verified over the decoded object, so they are closed: a new field breaks every deployed client. That is why the §XVI.6.4 `connector` field is added now (Q22 A, client work C4).
- The Gate-5 relay chain never checks the Delegation Certificate's e-mail domain, which §XVI.6.5 requires of every verifier. This belongs to the relay service (S7).
- Annex erratum candidate: §XVI.6.3 and one sentence on p. 15 say the responder is "named in the second block", while the C-class description on pp. 14–15 puts it in the third block. The client reads block 3.
- The production transport refuses loopback and private addresses without an override. The local test backend has to account for that (contract §10).
